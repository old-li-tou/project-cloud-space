# 新电脑验收

请在另一台 Windows 10/11 x64 电脑上，使用自己的 GitHub 账号克隆私有仓库或下载源码 ZIP。按 README 安装 Python 3.12，执行 setup.cmd，再启动 start.cmd。不复制旧电脑的 .venv、.state、凭据或项目内 .云端记录。

1. 在“网盘授权…”中填写自己的百度应用 App Key 和 Secret Key，打开浏览器完成授权，提交新取得的授权码。可继续使用原百度账号和应用。不要在 Issue 或聊天中发送密钥、令牌或授权码。
2. 创建独立测试项目和可丢弃的非空小文件，保留一份副本在云空间之外。添加项目，将测试文件放入云空间。
3. 等待上传、完整回读及索引核验结束，确认云空间内原件已释放，程序没有失败项。
4. 使用“恢复选中文件”，将恢复文件与保留副本比较大小及 SHA-256。可使用 PowerShell 的 Get-FileHash。
5. 通过“从云端恢复整个项目…”选择另一个独立测试项目：它应由旧电脑预先归档，新电脑未导入它的本地项目记录。恢复到新的空目录，核对内容及原始相对路径。只选测试项目，避免意外下载大型归档。
6. 再次恢复到相同位置，确认相同内容被跳过；如测试同名不同内容，确认原有文件没有被覆盖。

反馈时记录 Windows/Python 版本、失败步骤及脱敏后的接口错误码。首次授权、上传、文件恢复、无本地记录的项目恢复应分别标注通过或失败。离线自动测试通过不能代替这次实测。
