# 项目云空间 · Project Cloud Space

[English introduction](README.en.md) · Windows 源码版 v0.1.0 · MIT

把暂时不用的项目文件拖入“云空间”，自动上传到百度网盘。完整回读校验和云端索引备份都成功后，释放本地文件；需要时按原目录结构恢复。

这是个人文件归档工具，目前支持 Windows 10/11 x64、Python 3.12。中文界面，有 GUI 和 Agent CLI。不需要原先的百度 API 示例项目。

**这是会释放本地原件的归档工具。请先用可丢弃的小文件体验完整上传与恢复。云端文件和索引都在同一百度网盘账号，不是两个独立备份。**

## 实际案例：一个开发项目从 23.77 GiB 减到 5.58 GiB

2026-10-13，在一个包含固件、服务器和硬件测试工作区的个人项目中，使用可选的 `project-slimming` 技能分析文件用途，经用户批准后清理缓存、打包历史资产，再交给项目云空间归档。

| 指标 | 处理前 | 处理后 |
|---|---:|---:|
| 项目本地文件逻辑大小 | 约 **23.77 GiB** | 约 **5.58 GiB** |

本次本地文件逻辑大小减少约 **76.5%**。处理内容分为两类：

- **直接清理：** 删除有对应源码的 Python 缓存及指定本机测试产物，共 18,260 个文件，约 **200.64 MiB**。缓存会在后续运行时按需重新生成。
- **归档后释放：** 将重复依赖按两种不同内容去重保存，并按实验版本保存历史构建，共生成 **12 个独立 ZIP，约 1.56 GiB**。归档核验后释放 33 个目录、241,456 个原文件，逻辑大小约 **18.01 GiB**；扣除留在本地的清单与验证材料，该批次净减少约 **17.99 GiB**。

源码、Git 历史、未提交的受版本管理修改、主开发依赖、服务器运行环境，以及本次未选择归档的原始录音和测试证据均保留。历史工作区再次编译前，需要恢复对应依赖包。

**恢复验证做到了哪一步？** 先上传并下载恢复一个试验小包，核对包内 52 个文件的哈希；通过后才处理正式批次。12 个正式包均完成本地包内成员校验、云端完整回读和索引核验，然后才释放原件。正式批次涉及的 24 个仓库核对了 HEAD 和受版本管理内容，未发生变化；本地保留了成员清单、恢复映射和恢复说明。

这是一次真实项目的结果，数据来自该次会话和本地验证记录，经匿名汇总。容量按文件逻辑大小统计，不代表磁盘实际分配空间或保证其他项目获得同样收益。未执行全项目恢复演练、业务运行测试或历史环境重建验证。依赖去重、打包及包外原件清理由 Agent 按批准清单完成；云空间程序负责上传、回读校验、索引及其管理文件的释放，不会自行判断哪些项目文件可以删除。

## 安装

1. 安装 Python 3.12 x64（可选安装 Python Launcher）。将源码解压到自己可写的普通目录。
2. 双击 `setup.cmd`，在当前目录建立独立 `.venv` 并安装 `requirements.txt`。
3. 双击 `start.cmd`（或“启动云空间.cmd”）。

如果系统找不到 Python，可在终端指定其完整路径：

```powershell
.\setup.cmd "C:\Python312\python.exe"
```

虚拟环境不随源码分发；移动整个程序目录后，应移除旧 `.venv` 环境目录，再运行 setup.cmd 重新建立环境。只移除环境，保留 `.state` 和项目内全部归档记录。

## 首次授权

需要自己的百度网盘开放平台应用，以及有网盘 API 权限的账号。应用注册、审核、配额由百度决定；软件不能绕过这些限制。

1. 在[百度网盘开放平台](https://pan.baidu.com/union)创建适用应用，取得自己的 App Key 和 Secret Key。
2. 点击“网盘授权…”，填写这两个字段，点击“打开百度授权页面”。
3. 在百度页面登录并授权，将页面给出的授权码粘贴回软件并提交。授权码只能使用一次。
4. 看到“网盘授权成功”后添加项目。授权失败时检查应用权限与回调配置；本版使用 `redirect_uri=oob`。

软件不收集百度账号密码。凭据使用 Windows DPAPI 加密，保存在 `%LOCALAPPDATA%\ProjectCloudSpace\credentials.dpapi`，不在源码目录。另一个 Windows 用户或新电脑需要重新授权。

## 归档和恢复

- “添加项目…”会在项目根目录新建“云空间”。先启动软件，再把确定不在使用的文件移进去。
- 可一次拖入多个文件。稳定 10 秒后，串行上传、完整下载比对大小与 SHA-256、备份云端索引并回读核对，最后释放原件。
- 网络失败自动重试；明确限流后整队等待 70 分钟。原件保留，等待不是百度解除限制的保证。
- “恢复选中文件”恢复到项目下的“云空间恢复”。
- “从云端恢复整个项目…”不需要本机项目记录。选择云端项目与恢复父目录，按原目录结构还原，内容不同的同名文件保留后缀。
- 再次恢复到同一位置时，会校验已存在文件并跳过内容一致者。中断后可继续。

云端结构：`/项目云空间/项目云空间-项目名-编号/`，内部有数据文件和“归档索引”。不要手工改名、移动或删除需要恢复的云端数据及索引。

详见[使用说明](docs/usage.md)、[Agent 接口](docs/agent.md)、[开发和验证](docs/development.md)。

在另一台电脑上验证安装与授权时，可按[新电脑验收清单](docs/fresh-computer-test.md)逐项操作。

## 可选：让 Agent 分析项目瘦身

源码附带 [project-slimming 技能](skills/project-slimming/SKILL.md)，可以独立使用，也可配合项目云空间。它会分析保留、删除和归档候选，给出低影响、推荐、激进方案，并根据文件分布、恢复需求、传输成本和临时空间建议打包大小与分组；不会强制统一包大小或凑瘦身比例。

将源码中的整个 `skills/project-slimming` 文件夹复制到 Codex 的技能目录：默认 `%USERPROFILE%\.codex\skills\project-slimming`，自定义了 `CODEX_HOME` 则使用其 `skills` 子目录。安装后在目标项目中新建会话，主动调用：

```text
$project-slimming 分析当前项目的磁盘占用，给出推荐的瘦身方案和打包建议。先只分析，不修改文件。
```

技能不会自动触发；默认只读分析。具体删除、移动、打包和归档按你批准的清单执行。压缩包上传成功并不自动授权删除包外原件；释放原件前还需确认包内内容完整、云端归档完成且原件未变化。云空间恢复压缩包后，需要按随包清单解压恢复。

## 当前边界

- 程序运行时才监听；关闭或休眠期间不会自动上传，也没有开机自启或系统服务。
- 恢复已归档的普通非空文件。空目录、链接、目录连接、NTFS 权限/备用流不在恢复范围内。
- 不自动解压压缩包；不提供资源管理器占位文件或跨重启分片断点续传。
- 窗口心跳不等于网络进展；上传 100% 不等于归档完成。
- 保存的是可恢复文件版本，不是整个项目在某一时刻的事务快照。
- 云端索引文件名中的 SHA-256 检测损坏，不提供对抗恶意篡改的数字签名。
